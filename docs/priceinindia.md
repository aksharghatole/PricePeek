# Optional keyless multi-retailer provider
PriceInIndia documents a free read-only stateless MCP for compatible clients: https://www.priceinindia.website/mcp . It reports 100+ stores and hourly crawler refreshes, not guaranteed current checkout prices. The adapter requests one page of ten results, preserves the provider's buy redirects and citation pages, and displays the reported observation timestamp. Fair-use limits and Retry-After are respected; no bulk ingestion or purchase actions. Provider has no GTIN in its documented shape, so listings stay ungrouped.

Standalone public app use and redistribution terms are not verified. The production adapter remains disabled unless PRICEPEEK_PRICEININDIA_APPROVED=1 is explicitly configured after reviewing terms or obtaining permission. No account or API key. Mock transport tests cover parsing and protocol. A manually dispatched single-query probe is available for documented client evaluation; it does not activate public access or scrape site pages.
