- Amazon India Creators API provides catalog access for eligible affiliate partners. No credentials or permission confirmed. https://affiliate-program.amazon.in/creatorsapi/docs/en-us/introduction

Its terms do not expressly grant PricePeek redistribution rights; ask about app integration before relying on it for public use. https://www.priceinindia.website/mcp and https://www.priceinindia.website/terms
